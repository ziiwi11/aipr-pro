# 千寻 Windows 原生验收

状态：实机待验。测试对象必须是与Mac冻结源码同版的最终安装包。不要以Mac测试或文件哈希代替Windows运行证据。记录日期、版本、OS、CPU架构及每项结果；失败先保留证据与数据，修复后回归。

## 内置运行环境烟测

安装后用包内 Python 执行包内诊断文件（以实际安装目录为准）：

```powershell
& '.\resources\runtime\windows-x64\python\python.exe' '.\resources\diagnostics\windows-runtime-smoke.py'
```

需确认依赖导入、中文Excel读写及Playwright驱动启动。输出 `fullAppAcceptance: false` 表示烟测成功仍未代表软件验收。
