千寻达人运营 1.0.79｜交付与使用说明
版本：v1.0.79-rc.1（验收候选版）
更新日期：2026-10-09

一、交付方式
公开下载页：https://github.com/ziiwi11/aipr-pro/releases/tag/v1.0.79-rc.1
甲方无需登录 GitHub，进入 Assets（附件）下载对应安装包及本说明。
Mac Apple 芯片（M1/M2/M3/M4等）：Qianxun-Mac-M1-1.0.79-arm64.dmg；ZIP为同版备用包。
Windows 10/11 64位：Qianxun-Win-Setup-1.0.79-x64.exe；Portable为便携版。
当前未提供 Intel Mac 或 Windows ARM 专用包。Source ZIP为开发源码，普通用户无需下载。
可下载 SHA256.txt 与安装包核对文件完整性。
公开仓库包含软件源码和版本附件，不包含本次生产名单、联系人、模型密钥或店铺登录会话。甲方需要已有业务数据时，应单独确认交接范围，通过私密渠道交付软件备份；不要上传到公开仓库。

交付方执行顺序：
1. 确认甲方电脑系统和芯片，发对应安装包、说明及验收清单。
2. 在甲方实际电脑安装，并确认“系统设置”显示1.0.79。
3. 甲方本人登录店铺，配置自己的模型服务。
4. 新建独立测试任务，小批量跑完整流程，核对证据、联系人、名单与导出。
5. 暂停、退出、重开，确认数据和断点保留；测试备份恢复。
6. 记录实际测试结果和未完成项，再确认正式交付。不能只以安装成功作为全流程通过。

二、安装
Mac：打开DMG，把千寻应用拖入“应用程序”，再打开应用；ZIP可解压后复制应用。已有版本先暂停任务、正常退出，并备份数据，再替换应用。
当前Mac包仅有本机临时签名，尚未完成Apple正式签名公证。如果系统阻止打开，先核对来源和文件完整性，由电脑本人按系统提示决定是否允许；不要关闭系统安全或使用来历不明的绕过工具。
Windows：下载Setup，运行后按向导安装；便携版可放在有写入权限的固定目录运行。包内带Python及所需依赖，无需另外安装开发工具。若系统安全检查拦截，应先核对来源，由管理员处理；实际Windows全流程仍待实机验收。
软件可独立运行，无需打开Codex。平台采集和云模型分析需要联网。

三、首次配置
1. 打开“系统设置”，检查平台就绪状态和当前版本。
2. 打开“抖店浏览器”，由店铺本人登录有精选联盟权限的店铺，确认能进入达人后台。新电脑需要重新登录。
3. 打开“分析模型”，填写本账号的Jev配置，保存后执行连接测试。显示“已配置”不等于调用已验证；测试也可能产生服务费用。
4. 已保存配置不必反复输入；留空Key可保留原配置。密钥加密保存，系统要求的首次读取授权由本人完成。
5. “充值 / 账户”等入口用于访问服务方账户页面；本地Token记录不是官方余额或最终账单。费用与额度以服务方账单为准。
6. 千问用于手卡理解，服务来源为阿里云百炼，需独立配置。当前交付环境未验证百炼真实连接，不保证开箱即可调用；不可用时保留原文，用解析与手动填写完成任务设置，不用Jev密钥替代百炼密钥。

四、新建品牌任务
按顺序操作：先识别品牌手卡 → 选择类目 → 选择达人类型及出镜方式 → 核对并保存。
手卡可提供品牌、产品、卖点、达人要求和排除条件。AI有建议时，可选其中一项，也可自行输入；保存前必须核对。
类目应与精选联盟后台对应。美妆与个护家清属于独立后台类目，组合配置由软件分别处理并合并去重。
达人类型、真人出镜等要求用于作品审核，不能仅凭后台类目认定达人是真人口播。
填写目标人数；粉丝不限时保留不限配置。保持要求符合实际业务，证据不足的达人进入待复核，不为凑数放行。
保存任务不会自动采集，也不会自动发送消息。

五、自动采集
在“自动采集”核对当前任务、目标、类目和筛选条件，再点击开始或续跑。
软件自身完成发现候选、作品证据、模型判断、联系方式和入库。候选数、已处理数、合格入库数含义不同；判断进展应同时看实际阶段和新增正式名单。
平台冷却时等待恢复，不频繁刷新或重复启动；冷却、登录等待和证据复核会降低入库速度，不能保证固定每分钟一人。
需要暂时停止时点击暂停；继续时沿用软件断点。停止或结束本批会保留已有资料。
运行期间不要替换安装包，不同时启动第二个采集作业。若长时间没有变化，先记录当前状态和错误，再导出去敏诊断报告。

六、名单与复核
“联系与交付”：查看当前批次新收集的达人、联系方式、AI建联预览及交付文件。
“达人优选”：查看已完成或已结束的往期达人及历史联系、交付记录。
达人详情可查看已获取的身份、粉丝、销售等数据，以及作品证据、模型依据和联系人。没有采集到的字段不应被理解为0，也不保证所有达人所有字段齐全。
作品文字可能来自已保存精选联盟内容证据，包含作品标题或商品名；不能一律当作完整视频台词或抖音正文。
待复核表示证据不足或存在需处理的问题。人工备注不代表模型或平台已验证。
明文手机号、微信或邮箱只证明软件取得了所显示的联系人，不证明一定可联系、联系人属于本人或会回复；需另外验证。

七、联系与交付
先确认本批任务和名单范围。在“联系与交付”生成“当前名单交付包”，再运行一致性检查。
核对界面、JSON、Excel及两个队列中的人数和达人身份；不能把历史恢复记录当成本批新增。
交付内容以实际生成的文件为准，包含已获取资料和证据；人工核对异常后再交给业务人员使用。
AI建联仅用于选择与预览。导出待发送队列不代表已发送。本候选版交付验收未包含实际发送、同步授权及联系人可达性测试，勿把预览结果当作外发成功。

八、数据保存、迁移与更新
软件资料保存在本机；卸载、清理目录或更换电脑前先备份。
暂停任务后，在“系统设置”点击“备份任务与名单”，将备份保存在独立位置。
新电脑安装后，用“校验并恢复备份”选择软件备份；恢复到新目录，保留原资料，任务不会自动续跑。
备份包含任务、名单、证据、交付与复核记录，不包含API Key、登录会话和发送授权；新电脑需由本人重新完成这些配置。
恢复副本不应重复计算为新增达人。迁移后先确认任务、人数、联系人和证据可读，再开始作业。
后续更新从GitHub Releases获取；更新前暂停、备份、退出，再安装。不要直接复制开发源码当作应用升级，也不要删除用户数据目录。
跨Mac/Windows恢复也应在目标实机验证后使用，当前未取得跨平台实机验收通过证据。

九、常见问题
没有开始：检查店铺权限、模型连接、当前任务状态及平台就绪提示，不重复点击启动。
进度慢：区分平台冷却、重复候选、作品证据不足与真正的软件错误；重复页数不等于新增人数。
钥匙串提示：由电脑本人处理现有配置的读取授权，不反复重设密钥，不关闭系统安全。
联系人少或缺数据：查看候选/待复核原因和实际字段，不用默认值填充未知信息。
故障反馈：在“系统设置”导出去敏诊断报告，附版本、系统、故障发生时间、操作步骤及界面截图；不要发送密钥、登录验证码或公开发布客户联系人。
