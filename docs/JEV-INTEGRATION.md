# Jev 达人内容判断（本机配置，2026-10-01）

本机已启用 Jev 云端分析（jev-latest），使用已有 TypeSafe 凭证。凭证存储在用户配置目录，权限 0600，不进入源码或安装包。系统设置显示配置状态与模型。

## 筛选行为

等级、销量、排除条件、主页与内容证据等硬条件由程序核验。通过后，Jev 基于本次产品规则及作品内容判断匹配度，替代类目及真人口播的简单关键词匹配。

- supported：保持原来的推荐或待补联系方式结论。
- review_conflict：暂不推荐，待人工复核。
- uncertain、服务失败、缺少具体作品证据：待内容复核，不进入正式名单或建联队列。
- 实时流程中的后两类保留在 evidence_reviewing，允许续跑重新复核。

置信度低于 0.65 会进入待复核。该阈值为本机初始配置，已用示例验证流程，尚未用真实标注达人集校准。Jev 不处理视频像素，仅判断提供的作品标题、文本及证据；不能据此宣称看过视频。

结果保留结论、置信度、选项概率、模型、内容证据哈希及后端耗时。程序显示的理由是对应结论的说明，不是模型生成的推理。

## 配置

用户目录：~/.config/jev-integration/
- aipr-pro.json：云端模型、凭证、decision_mode、confidence_threshold。
- enabled-apps：启用应用列表，包含 aipr-pro。

原有本地网关模式仍兼容。本机直接使用 https://api.typesafe.ai/v1/systemone，不依赖 8771 网关或其他应用运行。

后端 393 项、桌面 40 项测试通过；云端匹配、冲突、缺证据三类示例验证通过。示例不计为真实采集达人。
